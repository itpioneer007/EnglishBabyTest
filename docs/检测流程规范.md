# 检测流程规范

## 9步检测流程

### 步骤1：获取APP
- 下载正式版英语宝（应用市场）或预发布版（技术同事提供）
- 安装到测试设备

### 步骤2：登录
- 输入灰度账号及密码
- 确认登录成功（无报错、进入主界面）

### 步骤3：选择版本年级册、进入模块
- 选择对应版本、年级、册次
- 点击进入目标模块

### 步骤4：检查单元目录
- 部分模块进入后呈现单元目录
- 检查目录文字是否正确（无错字、无乱码、与预期一致）

### 步骤5：进入单元
- 点击对应单元标题进入单元内容

### 步骤6：逐题检查（六项检查）
对每道题执行以下六项检查：

#### 检查项1：题干文字
- 判定标准：题干文字内容与脚本完全一致
- 检查要点：无错字、无漏字、无多字、无乱码

#### 检查项2：题目内容文字
- 判定标准：题目内容文字与脚本相符
- 检查要点：
  - 是否与脚本相符
  - 是否显示完整（无截断）
  - 是否有知识性错误
  - 是否有逻辑错误

#### 检查项3：题目内容图片
- 判定标准：图片与脚本相符
- 检查要点：
  - 是否与脚本相符（图片内容正确）
  - 是否显示完整（无裁切、无缺失）
  - 是否与题目内容匹配
  - 是否有不合逻辑之处

#### 检查项4：作答验证
- 判定标准：题目能正常作答
- 检查要点：
  - 答案能否正确输入
  - 答案能否完整输入
  - 其他形式作答是否正常（口语题录音、拖拽题等）
  - 作答后UI反馈是否正常

#### 检查项5：答案与知识点
- 判定标准：答错后显示的内容正确
- 检查要点：
  - 题目答案是否正确
  - 知识点是否正确
  - 听力题：听力材料文字是否正确
  - 听力材料文字是否与听力音频相符
- 注意：部分模块需要答错才会显示以下内容

#### 检查项6：听力音频
- 判定标准：听力音频完整且正确
- 检查要点：
  - 音频是否有且完整
  - 音频是否能正确播放
  - 音频角色设置是否正确
  - 音频内容是否与题目相符
- 注意：仅听力题需检查此项

### 步骤7：流程完整性检查
- 每道题检查完后点击进入下一题
- 检查全部内容是否完整
- 检查模块是否能正常完成全部流程
- 无卡顿或无法进入下一题的情况

### 步骤8：报告页检查
- 部分模块答题完成后有报告
- 检查报告内容是否正确：
  - 得分是否正确
  - 显示的知识性内容是否正确完整

### 步骤9：缺陷上报
- 检查过程中发现的错漏需：
  1. 截图保存证据
  2. 在TAPD上填写具体情况
  3. 提交给后台操作人员进行修改

## 双端要求
- Android和iOS两个端口都需要检测
- 同一问题可能在两个端口表现不同
- 两个端口的检测结果独立记录
