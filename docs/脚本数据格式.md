# 脚本数据格式规范

## 数据结构

每道题的预期数据采用以下JSON结构：

```json
{
    "question_id": "Q3A-U1-001",
    "module": "单词学习",
    "grade": "三年级上册",
    "unit": "Unit 1 Hello",
    "version": "v2.1",
    "question_type": "选择题",
    "stem_text": "选择正确的单词补全句子: Hello, ___ name is Tom.",
    "content_text": "A. my  B. I  C. me  D. mine",
    "image_url": "",
    "image_description": "",
    "audio_url": "",
    "listening_text": "",
    "audio_roles": "",
    "correct_answer": "A",
    "knowledge_points": ["物主代词", "my的用法"],
    "order": 1
}
```

## 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|:----:|------|
| question_id | string | 是 | 题目唯一标识，用于关联检测结果 |
| module | string | 是 | 模块名（如"单词学习"） |
| grade | string | 是 | 年级册（如"三年级上册"） |
| unit | string | 是 | 单元名 |
| version | string | 否 | 版本号 |
| question_type | string | 是 | 题型：选择题/填空题/听力题/口语题/拖拽题/其他 |
| stem_text | string | 是 | 题干预期文字（检查项1的比对源） |
| content_text | string | 否 | 题目内容预期文字（检查项2的比对源） |
| image_url | string | 否 | 预期图片资源URL（检查项3的比对源） |
| image_description | string | 否 | 预期图片内容描述（无URL时用于LLM判断） |
| audio_url | string | 否 | 预期音频资源URL（检查项6，听力题必填） |
| listening_text | string | 否 | 听力材料文字（检查项5/6，听力题必填） |
| audio_roles | string | 否 | 音频角色设置（如"男生A/女生B"） |
| correct_answer | string | 是 | 正确答案（检查项5的比对源） |
| knowledge_points | string[] | 否 | 知识点列表（检查项5的比对源） |
| order | int | 是 | 题目在单元中的顺序 |

## 题型与字段适用关系

| 题型 | stem_text | content_text | image_url | audio_url | listening_text | correct_answer |
|------|:---------:|:------------:|:---------:|:---------:|:--------------:|:--------------:|
| 选择题 | ✅ | ✅ | 可选 | — | — | ✅ |
| 填空题 | ✅ | ✅ | 可选 | — | — | ✅ |
| 听力题 | ✅ | ✅ | 可选 | ✅ | ✅ | ✅ |
| 口语题 | ✅ | ✅ | 可选 | 可选 | 可选 | ✅ |
| 拖拽题 | ✅ | ✅ | ✅ | — | — | ✅ |

## 数据源接入方式

### 方式1：API（推荐）
```
GET /api/questions?module=单词学习&grade=三年级上册&version=v2.1
Authorization: Bearer <token>

Response: { "questions": [ {...}, {...} ] }
```

### 方式2：数据库
```sql
SELECT * FROM questions
WHERE module = '单词学习' AND grade = '三年级上册'
ORDER BY `order`;
```

### 方式3：文件（Excel/JSON）
Excel格式：第一行为表头，每行一道题，列名对应字段名。

## 数据完整性校验

获取数据后应校验：
1. 必填字段不为空
2. question_id 唯一
3. order 连续无缺
4. 听力题的 audio_url 和 listening_text 非空
5. 有图片的题目 image_url 或 image_description 非空
