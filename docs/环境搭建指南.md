# 环境搭建指南

## 1. Android 开发环境

### 1.1 安装 ADB

**方式A：安装 Android SDK Platform Tools（推荐）**
1. 下载：https://developer.android.com/tools/releases/platform-tools
2. 解压到固定目录（如 `C:\Android\platform-tools`）
3. 添加到系统 PATH 环境变量

**方式B：通过 Android Studio**
1. 安装 Android Studio
2. SDK Manager → SDK Tools → 勾选 "Android SDK Platform-Tools"

验证安装：
```bash
adb version
# 输出应包含版本号
```

### 1.2 连接设备

**真机：**
1. 手机设置 → 开发者选项 → 开启"USB调试"
2. USB 连接电脑，手机弹出授权对话框点"允许"
3. 验证：`adb devices` 应显示设备序列号

**模拟器（备选）：**
- 雷电模拟器：默认端口 5555，`adb connect 127.0.0.1:5555`
- 夜神模拟器：默认端口 62001
- Android Studio AVD：自带 ADB 连接

### 1.3 安装英语宝 APP

```bash
# 正式版：在设备应用市场下载安装
# 预发布版：通过ADB安装APK
adb install -r 英语宝_v2.1_pre-release.apk
```

### 1.4 获取包名和启动 Activity

```bash
# 方法1：查看已安装包
adb shell pm list packages | grep yingyu

# 方法2：查看当前前台Activity
adb shell dumpsys activity activities | grep mResumedActivity
```

将获取到的包名和 Activity 填入 `config.py`。

## 2. iOS 开发环境（可选，后期扩展）

### 2.1 前置条件
- macOS 系统（XCUITest 仅支持 Mac）
- Xcode 14+
- iOS 真机或模拟器
- Appium 2.x + XCUITest 驱动

### 2.2 安装 Appium

```bash
npm install -g appium
appium driver install xcuitest
```

### 2.3 WebDriverAgent 配置
1. 克隆 WebDriverAgent
2. 用 Xcode 打开，配置签名证书
3. 编译部署到 iOS 设备

### 2.4 获取 Bundle ID
```bash
# 通过 ideviceinstaller（需安装 libimobiledevice）
ideviceinstaller -l
```

## 3. 多模态 LLM API 配置

### 3.1 选择提供商

| 提供商 | 模型 | 优势 | 获取方式 |
|--------|------|------|---------|
| OpenAI | gpt-4o | 视觉能力强 | https://platform.openai.com |
| Anthropic | claude-3-5-sonnet | 长文本理解强 | https://console.anthropic.com |
| 智谱AI | glm-4v | 国内访问快、中文好 | https://open.bigmodel.cn |
| 阿里通义 | qwen-vl-max | 国内访问快、性价比高 | https://dashscope.aliyun.com |

### 3.2 配置
在 `config.py` 的 `LLM_CONFIG` 中填入：
```python
"provider": "openai",  # 或 zhipu / dashscope
"api_key": "sk-xxxx",
"model": "gpt-4o",
```

### 3.3 成本估算
- 每题约2次LLM调用（提取+验证）
- 每次调用约 1000-2000 token（含图片）
- GPT-4o: 约 ¥0.05-0.10/题
- GLM-4V: 约 ¥0.02-0.05/题
- 100题模块约 ¥5-10（GPT-4o）或 ¥2-5（GLM-4V）

## 4. TAPD 对接

### 4.1 获取 API Token
1. 登录 TAPD → 公司管理 → API应用
2. 创建应用，获取 API User 和 API Password
3. 获取项目 Workspace ID（TAPD项目URL中可见）

### 4.2 配置
在 `config.py` 的 `TAPD_CONFIG` 中填入：
```python
"api_token": "your_token",
"workspace_id": "12345678",
"default_assignee": "处理人账号",
```

### 4.3 或使用 WorkBuddy TAPD 连接器
在 WorkBuddy 连接器管理中启用 TAPD 连接器，授权后可直接通过 WorkBuddy 调用 TAPD API。
