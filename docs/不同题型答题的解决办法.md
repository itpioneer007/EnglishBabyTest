# 不同题型答题的解决办法（听力专项·测试模块）

> 本文记录听力专项「测试」模块中各题型的识别特征与自动答题办法。
> 坐标全部走 `common/tools.py` 的 `S()/S_h()/S_w()`（基准 1080×2400 动态换算），换手机无需改坐标。
> 总题数从右上角 `X/Y` 读取（右侧那位是总题数）。

---

## 1. 图片排序题（如第 16 题）

### 识别特征
- 出现 **5 张大图卡片**：`clickable=true`、宽度 `300~700`、纵向 `y 700~1900`。
- 底部有图片槽（方框/圆圈），`resource-id` 常含 `img_sort_btn`。
- 题干含「排序」字样。

### 作答办法（模式 A）
1. **依次点击 5 张大图**（按界面出现顺序：从上到下、从左到右）。
2. 每点一张，序号按点击顺序**自动**填入对应图片槽。
3. 5 张点完 → 底部出现「检查」→ 点「检查」。
- 正确顺序由听力音频决定；自动化按视觉顺序点击，由 App 判定对错（答错出「下一题」继续）。

### ⚠ 易错点
- 不要把图片排序误判为「单选/判断」：图片卡片是 `clickable=true` 的 `LinearLayout`，不是 `CheckBox`。
- 不要等「圆形序号按钮」出现——图片排序**没有**底部序号按钮，直接点图即可。

---

## 2. 方框排序题（如第 17 题，通常为最后一题）

### 识别特征
- 出现 **5 个方框**：`clickable=true`、宽 `~228`、纵向 `y 700~1900`，内含 `question_title_tv`（句子）+ `select_tv`（填入的序号）。
- 题干含「排序」，**无大图**、无 `img_sort_btn`。
- **左侧 `new_tv_sort` 是句子自带序号（非点击目标）**，不要去点它。

### 作答办法（模式 B）
1. **点第一个方框**激活输入框（只需点一次第一方框，App 会按顺序往后填）。
2. 底部出现**序号按钮 1~5**（2 行布局：第 1 行 4 个、第 2 行左 1 个；宽 `242`、纯绘制、无文字、`clickable=true`）。
3. **按位置顺序点 1→2→3→4→5**（第 1 行从左到右，再第 2 行最左）。
4. 5 个方框依次出现 `1、2、3、4、5` 后，作答完成，此时「检查」已出现，按需点检查。

### ⚠ 关键机制（已真机踩坑验证）
- **点完序号 1 后，页面下方出现「检查」按钮，导致序号 1~5 整体向上移动一点**。
  → 因此**每次点完一个序号，都必须重新检测序号按钮位置再点下一个**，绝不能预先快照旧坐标后依次点（旧坐标会因上移错位，最后一两个会落到「检查」上）。
- **序号按钮是「可复用」的**：点击不消失，每点一次由 App 按 `1→2→3→4→5` 顺序自动填入下一个方框。所以引擎里「每次重新取最左上序号按钮点」也能成立，但按位置顺序点 1~5 逻辑更清晰、可读。
- **别把「检查」当序号按钮**：「检查」按钮宽可能落入 `200~300` 区间，检测序号按钮时必须**排除 `text` 含「检查/检测/下一题/查看报告」的控件**（或直接按 `width>300` 排除「检查」，其宽度通常远超 300）。

### 检测/点击要点（代码层）
- 序号按钮识别：`clickable=true` 且 `200 < width < 300` 且 `x 起点 != 58` 且 `1680 < y < 2260`，并排除有文字的关键按钮。
- 方框识别：`clickable=true` 且 `100 < width < 300` 且 `700 < y < 1900`。
- 两种排序都走 `engine._handle_sort_question(d, {})`；引擎内部靠「有无大图」自动分 A（图片）/ B（方框）模式。
- 早期曾把 Q17 误路由到 `_handle_sentence_sort`（圆圈排序），已修正为统一走 `_handle_sort_question`。

## 3. 选择 / 判断 / 填空（常规题型）

- **选择（A/B/C/D）**：点对应字母控件。
- **判断（T/F）**：控件是 `CheckBox` 且 `clickable=false`，需**整节点单独取 `text` 匹配** `T/F`，不能要求 `text` 与 `clickable` 同节点（否则匹配不到）。
- **填空**：用 `FastInputIME` 注入（`d.set_fastinput_ime(True)` → `d.send_keys(...)` → `d.press("back")`），绕过系统键盘拦截。

---

## 4. 通用注意事项
- 答完一题点「检查/检测」；答错出「下一题/重新答题」，答对进下一题。
- 最后一题检查后出「查看报告」，**不要把它当成普通题提前退出**。
- 所有坐标用 `S()` 换算；切年级/版本见 `common/setup.py`、`common/tools.py`。
